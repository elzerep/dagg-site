# Bilder

## Kedjan

    codex exec "…brief… save to assets/img/NAME.png"
    cwebp -q 82 -resize 1600 0 assets/img/NAME.png -o assets/img/NAME.webp

PNG:erna som kommer ut väger 2–3 MB och ska aldrig ligga på sajten. WebP vid
q82 och 1600px bredd landar runt 100 KB, vilket är 24 gånger mindre utan
synlig förlust på mjuka ytor.

Behåll PNG:en lokalt som original. Bara `.webp` refereras från sidorna.

## Briefen — vad som måste stå i varje

**Paletten, uttömmande.** `#F0EEE6` grund, `#E8E6DC` halvton, `#141413`
sparsamt, `#B85C3E` som enda accent och på liten yta.

**Förbjudet, uttryckligen listat.** Neon, gradienter mot blått eller lila,
glödande kanter, kretsar, geometriska nät, svävande kuber, människofigurer,
text eller bokstäver, logotyper. Utan listan kommer modellen att leverera
AI-stockbild.

**Vad bilden inte är.** Skriv ut att det inte är ett diagram och inte en
illustration av teknik. Annars ritas ett nätverk.

**Tonen.** Tyst, varm, dyr, genomtänkt. Den ska se ut att höra hemma hos ett
bolag som seniora människor anförtror konfidentiellt arbete.
