What this page is for

  • The header and footer are static markup in the delivered file, so the page is complete with JavaScript disabled.
  • The composition above contains no copied header or footer DOM.
  • Every stylesheet, script, font and icon is a local reference.
  • Icons are vendored Lucide files referenced as images; there is no inline vector markup and no text symbol used as an icon.
  • Repeating the build over unchanged sources rewrites the same bytes.

Direction script: not run. This value is the only thing direction.js changes; with scripts blocked it stays as written, which is the point.
