# Home display addendum

Status: binding for the selected Home position hero  
Date: 2 September 2026  
Decision owner: Christian Pérez  
Integration owner: Codex

The selected Home direction deliberately uses Newsreader for the position H1.
This is a display exception, not a change to the global type system.

- Home H1: Newsreader variable, weight 420, fluid endpoint up to 92 px on wide
  desktop, with a maximum line length of approximately 15 characters.
- All supporting-route H1s and all interface labels continue to use the
  accepted token roles.
- The serif H1 must sit on warm paper outside the hero image and retain a clear
  hierarchy against the sans-serif lead, navigation and actions.
- At narrow widths the H1 must reflow without manual line breaks, clipping or
  horizontal overflow.

The exception exists because the founder-selected composition relies on an
editorial proposition above a precise causal image. It must not be generalized
to product carriers, navigation or system readouts.
