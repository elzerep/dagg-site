## 5. Visual and interaction contract

- The page is one calm, warm, editorial world.
- Home's generated image family is Decision Field, with restrained finite
  Machine Signal only where it explains a real state change.
- Operational Evidence is not a third Home image family. The execution proof
  is a coded, inspectable artifact; it does not authorize a new photographic or
  cinematic grammar.
- Use the frozen hero pair from `slot-manifests/a.json`:
  `p4r7-a2-home-hero-02-desktop` and
  `p4r7-a2-home-hero-02-mobile`.
- V1 hero is a still. Do not fake before/resolved states when approved start
  frames do not exist.
- Home has one contained proof instrument, not a terminal wall, dashboard,
  card collection or node graph.
- The only enhanced page-local interaction is the reader-controlled three-state
  operating record. It does not autoplay and it stops after a selected state.
- Global Build navigation retains its accepted adaptive preview behavior.
- No decorative icons, ambient loops, particles, parallax, fake typing,
  reveal-gated default copy or biological/circuit ambiguity.

## 6. Responsive contract

The same semantic Home must work at:

- 1440 x 900;
- 1366 x 768;
- 1280 x 720;
- 1024 x 768;
- 768 x 1024;
- 390 x 844;
- 360 x 800;
- 320 x 800.

Use one DOM reading order. Use the separately authored mobile hero source.
No horizontal document overflow, clipped essential copy or desktop image crop
on tablet portrait/mobile is permitted. Hover must have focus/tap equivalence.
Reduced motion and no-JavaScript must retain the same conclusion and complete
default reading path.

## 7. Density and rhythm gate

The accepted source baseline is:

- 291 default-visible Home words; 295 only when Impact is enabled;
- 26 progressive words;
- 49 first-screen words;
- 4.5-6.0 screens including the footer at 1280 x 720.

Do not optimize one number at the expense of visible quality. The rendered page
must still feel edited, calm and continuous: no empty viewport, no giant image
blaffor and no compression that makes the copy heavy.

## 9. Stop conditions

Stop and report rather than improvise if:

- exact copy cannot fit without falling below the accepted type floor;
- the frozen hero cannot preserve its protected events at a required viewport;
- the shared component layer prevents correct semantics or keyboard behavior;
- implementing a required behavior would require editing a file outside the
  owned set;
- a local reference does not resolve.

No publication or deployment is authorized.
