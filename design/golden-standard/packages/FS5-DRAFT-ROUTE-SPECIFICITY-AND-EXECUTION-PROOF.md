## 1. Why this package exists

The FS4 evidence set establishes a coherent visual and responsive baseline and
a strong founder-selected Home. It is not yet a golden-standard release
candidate. The latest failure-first review leaves the following gaps:

1. the supporting-route first screens repeat too much of the same warm-paper,
   statement-plus-tactile-image composition;
2. WorkGraph and Build describe execution more convincingly than they let the
   reader witness it;
3. the Home execution sequence is generic where one concrete, bounded operating
   thread would make Dagg's capability legible;
4. the Home autonomous sequence does not yet pause on hover and keyboard focus;
5. FS4 lacks a reproducible whole-site browser runner and the complete evidence
   bundle required by its own contract.

This pass does not reopen the brand, palette, typography, navigation topology,
Home hero, Home six-act narrative, route headline spine or Assessment
composition. It turns an accepted visual world into a more specific product
experience and closes the missing operating evidence.

Fable 5.1's failure-first review and original activation read are complete. A
later scope-reconciliation read required doc-only corrections before dispatch;
those corrections are incorporated here and in the lane packages. The shared
chrome slice may proceed through Codex Lane C. The two bounded Fable writer
lanes remain paused until Fable confirms the current contract and manifest
hashes after the narrow four-label ownership amendment. After that verdict,
implementation may proceed only through the mutually exclusive FS5 file scopes.
