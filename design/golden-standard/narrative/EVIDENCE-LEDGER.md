## Proof mechanics

### WorkGraph

Do not show a node network. Show one readable company-context record that gains depth while its identity stays constant.

The record contains:

- **Evidence:** approved source, captured statement, system touched, provenance.
- **Operating reality:** work item, owner, handoff, exception, unresolved decision.
- **Decision state:** selected outcome, reason, boundary, next accountable owner.

`Connect → Decide → Build → Learn` changes how the same record is used.
Governance remains an invariant across all four states. The lifecycle does not
replace the record with unrelated screens.

### Factory

Pass the same record into one two-mode build instrument:

- **Automate what stays:** retained system, approved tool connection, required context, proposed agent action, evaluation, human approval, disable/rollback.
- **Rebuild what should change:** target workflow contract, application boundary, data/interface requirements, software behavior, acceptance tests, accountable release owner, migration and way back.

Valid state sequence: `Context received → build plan → evaluation → ready for governed review`.

Both `Automate what stays` and `Rebuild what should change` require their own visible build plan. The rebuild plan must name the target workflow, application boundary, interfaces, behavior, acceptance test, accountable release owner and way back.

### Operating record

Show control, not a system Dagg claims to operate:

1. Intent received.
2. Approved context resolved.
3. Action proposed; nothing executed yet.
4. Material boundary triggered; action withheld.
5. Human decision recorded with accountable owner.
6. Outcome and concrete way back recorded.

Visible fields include actor, proposed action, permission boundary, material exception, decision, owner, evidence reference and reversal path.

## Acceptance gate

P1 fails if:

- a visible claim lacks P/R/V/C/X status;
- an artifact-bearing page lacks the exact shared page disclosure before its first constructed artifact;
- a representative artifact lacks its local provenance label;
- customer-like detail can be mistaken for a case;
- `live`, `production` or present managed operation is implied;
- WorkGraph is rendered as a node cloud or becomes the whole company promise;
- Factory lacks a concrete bill of materials;
- the operating record lacks a stop, human decision, owner and way back;
- a CEO must understand graph architecture before understanding Dagg;
- `Systems operated` appears as current evidence or category.
