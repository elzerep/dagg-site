# P4R6 frozen image slots

Each direction manifest freezes the visual job before candidate generation.
`unassigned` is a hard activation blocker, not permission to substitute a
moodboard image. A deliberately unused slot must be marked `retired` and include
an explicit reason; `retired` is never represented as `unassigned`. Candidate
IDs must exist in `../ASSET-REGISTRY.json`, and both builders receive the same
frozen bank and hashes simultaneously.

The first manifests deliberately do not select the P4R5 carrier. P4R5 proves the
system; A, B and C must each earn the asset that best expresses its thesis.
