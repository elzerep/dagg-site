## Page job

Home is the concise executive view of Dagg. It opens with the future company,
explains the operating-model shift, introduces WorkGraph and Dagg Factory only
after the consequence is clear, proves one governed execution thread and ends
with Dagg's accountable role and one bounded next move.

The six-act headline spine is immutable:

1. Build the company AI makes possible.
2. AI-native changes who executes — and who decides.
3. Start with how the company really works.
4. The decision becomes a working system.
5. Every operating cycle makes the next one better.
6. One partner, from direction to accountable release.

## Shared operating thread

Act 3 places the following disclosure before the first identifier:

`Constructed example, not client data or a production deployment.`

It then shows:

- `Context record — WG-034`
- `One governed exception, carried through`
- `Owner — Finance owner.`
- `Permission — Prepare only. Never release.`

Act 4 continues the same identity and adds the static request:

`Prepare this supplier payment exception for review.`

The finite sequence then resolves through:

1. Operating reality — The invoice and receipt disagree.
2. Decision retained — Automate preparation. Keep human approval for release.
3. Governed execution — The agent prepares the draft. It cannot release payment.
4. Evidence returns — The finance owner decides; the result and evidence update the same record.

Resolved status: `Human decision recorded. Release remains withheld.`

Running status: `Operating change in progress`  
Paused status: `Operating change paused`

## Interaction contract

- The sequence starts once when at least 35 percent visible and stops on state 4.
- Request remains static and is not a fifth state.
- Non-touch pointer hover over the state list pauses; leaving resumes only that
  pause source.
- Focus on an existing interactive descendant pauses; no state row becomes a
  junk tab stop.
- Explicit Pause remains authoritative until explicit Resume.
- Controls have fixed width so state changes never reflow the identity row.
- Reduced motion resolves immediately and hides Replay.
- No JavaScript renders Request and all four states in source order, exposes the
  resolved status `Human decision recorded. Release remains withheld.` and hides
  inert controls.
